# ClaudeSkills

- Commit and push straight to `main` in this repo. Don't open PRs.
- Run `tests/run.sh` before pushing.
- Every change to a skill must update `README.md` in the same commit, including its plain-language explanation and examples.
- Keep this repo clean enough to go public: no secrets, personal data, private paths, or references to private projects. Personal config belongs in the private `ClaudeConfig` repo.
